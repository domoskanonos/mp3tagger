# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in radio-ripper-tag, please report it privately via [GitHub Security Advisory](https://github.com/domoskanonos/radioripper/security/advisories/new).

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.1.x   | :white_check_mark: |
| < 2.1   | :x:                |
